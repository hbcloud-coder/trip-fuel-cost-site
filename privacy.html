Privacy Policy for Trip Fuel Cost

Effective Date: [Insert date]

Trip Fuel Cost is a Chrome extension that estimates driving route fuel costs and optional toll or fee costs while users plan routes in Google Maps.

Information the extension handles

Trip Fuel Cost reads visible route information on Google Maps pages, such as driving route distance and route-related text, only to calculate and display estimated trip costs.

The extension stores user settings locally using Chrome storage. These settings may include fuel price, vehicle efficiency, fuel type, unit preference, toll or fee amount, round-trip setting, and selected vehicle lookup preferences.

The extension may contact FuelEconomy.gov when the user uses the vehicle MPG lookup feature. This request is used only to retrieve public vehicle fuel economy information.

Information the extension does not collect

Trip Fuel Cost does not collect names, email addresses, payment information, health information, authentication information, personal communications, browsing history, or GPS location.

How information is used

Information is used only to provide the extension’s single purpose: estimating route fuel costs and optional toll or fee costs while planning routes.

Data sharing

Trip Fuel Cost does not sell user data. The extension does not share user settings with third parties. Vehicle lookup requests may be sent to FuelEconomy.gov only when the user uses the MPG lookup feature.

Data storage

User settings are stored in Chrome storage so the user does not need to re-enter them each time. Route information read from Google Maps is processed locally in the browser and is not stored by the extension as a trip history.
